# New World Vault

**[azothvault.com](https://azothvault.com)** · A free fan site for **New World: Aeternum** (Season 10): builds, loadouts, bosses, expeditions, crafting and tradeskill planning in one place.

![New World Vault home page](screenshot.png)

## What's on the site

| Section | What you get |
|---|---|
| Builds and loadouts | Weapon builds with gems, charms and perks, plus a loadout builder with attribute sliders and breakpoints |
| Expeditions and raids | Each expedition and its mutation levels (M1 to M3), bosses and drops |
| Items and artifacts | Searchable items, all 72 artifacts, and where things drop |
| Crafting | Recipes, shopping lists and where to gather each material |
| Tradeskill planner | Cheapest and fastest routes to level every tradeskill |
| Community | Sign in with Discord to save loadouts, comment and rate builds |
