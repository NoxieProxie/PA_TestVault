# Contributing

Azoth Vault is run by one person, so the easiest way to help is to tell us what's wrong or missing.

## Spotted wrong data?

Open an issue with the **report** form. Include the page, what it says, what it should say, and a source if you have one (a screenshot from the game works well).

## Want to suggest a build or guide?

Sign in on [azothvault.com](https://azothvault.com) with Discord and use the editor there. Submissions are checked before they go live.

## Code changes

Pull requests are welcome for small fixes. For anything bigger, open an issue first so we can agree on it before you spend time on it.

## Please don't

- copy guides or videos from other creators without permission,
- include personal data, tokens or keys in issues or pull requests.
